# PythonIA_EAN

## Descripcion del curso

Repositorio utilizado en el curso de Inteligencia Artificial de EAN.
Contiene ejemplos y ejercicios practicos desarrollados durante las clases,
incluyendo el uso de Python y modelos de lenguaje con Groq.

## Prerrequisitos

Antes de comenzar el curso, debes tener instalado:

- **Python 3.10 o una version posterior**. Puedes descargarlo desde
  https://www.python.org/downloads/. Durante la instalacion en Windows, marca la
  opcion **Add python.exe to PATH**.
- **Visual Studio Code**. Puedes descargarlo desde
  https://code.visualstudio.com/.
- La extension **Python** de Microsoft en Visual Studio Code.
- Una cuenta y una API Key de Groq. Puedes crearla en
  https://console.groq.com/keys.

Verifica la instalacion de Python desde la terminal:

```bash
python --version
```

En algunas instalaciones Linux o macOS utiliza:

```bash
python3 --version
```
